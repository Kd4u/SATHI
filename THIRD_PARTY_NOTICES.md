# Third-party components

Dependencies remain under their own upstream licenses. This list identifies the principal direct components; it is not a replacement for upstream notices or transitive license review before distributing a build.

| Component | Purpose | Upstream |
| --- | --- | --- |
| Firebase Apple / Android SDKs | Authentication and Firestore | https://github.com/firebase/firebase-ios-sdk · https://github.com/firebase/firebase-android-sdk |
| Google Sign-In for Apple | Google account sign-in | https://github.com/google/GoogleSignIn-iOS |
| AndroidX Credentials | Native Android account selection | https://developer.android.com/jetpack/androidx/releases/credentials |
| Google Identity Google ID library | Google ID token credential | https://developers.google.com/identity/android-credential-manager |
| CoreXLSX | Apple Excel import | https://github.com/CoreOffice/CoreXLSX |
| XMLCoder / ZIPFoundation | CoreXLSX dependencies | https://github.com/CoreOffice/XMLCoder · https://github.com/weichsel/ZIPFoundation |
| Gradle wrapper | Android build launcher | https://github.com/gradle/gradle |

Apple frameworks and Android SDK APIs are supplied by their respective platforms and are not redistributed as SATHI source. No model weights or third-party timetable data are included.
