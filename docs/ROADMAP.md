# Community roadmap

## MVP verification

- [ ] Verify Android Google sign-in and account-isolated two-device sync end to end.
- [ ] Add Firebase emulator tests for per-account rules and revision conflicts.
- [ ] Establish real Android 10 runtime coverage alongside newer phones.
- [ ] Verify Today/three-day widget content and background reminder delivery.

## Cross-platform parity

- [ ] Android semester archive viewing and safe next-semester import.
- [ ] Full Android notebook/page creation, covers, page selection and PDF export.
- [ ] A documented, portable drawing representation or safe Apple preview export for Android viewing.
- [ ] More accessible tablet/large-screen Android layouts.
- [ ] Review availability guards and lower Apple deployment targets where possible.

## Polish and contributor experience

- [ ] Curated, privacy-safe screenshots for each platform.
- [ ] Broader synthetic Excel fixtures, including multi-sheet first-year sections.
- [ ] Device lifecycle, offline conflict and notebook scale regression tests.
- [ ] Improve localization and large-text/screen-reader coverage.
- [ ] Document a repeatable maintainer release/checksum/signing process.

Issue discussions and focused pull requests are welcome. These are planned areas, not claims that the MVP already supports them.
